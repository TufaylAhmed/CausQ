# Partner logos

The partner strip on the home page looks for an SVG at each path below. **Until
a file exists, it shows a clean text wordmark instead** — so the strip always
looks intentional and never shows a broken image.

To use official logos, download each brand's SVG from its press / brand-assets
page and save it here with the matching filename. Monochrome / single-color
SVGs look best (the strip greyscales them and reveals color on hover).

| File            | Brand                |
|-----------------|----------------------|
| `cisco.svg`     | Cisco                |
| `juniper.svg`   | Juniper Networks     |
| `arista.svg`    | Arista Networks      |
| `paloalto.svg`  | Palo Alto Networks   |
| `fortinet.svg`  | Fortinet             |
| `aruba.svg`     | HPE Aruba Networking |
| `extreme.svg`   | Extreme Networks     |
| `nvidia.svg`    | NVIDIA               |
| `nokia.svg`     | Nokia                |
| `vmware.svg`    | VMware               |
| `zscaler.svg`   | Zscaler              |
| `f5.svg`        | F5                   |

To change which brands appear, edit the `PARTNERS` array in
`assets/js/main.js`.

> **Trademark note:** these are third-party marks. Only display logos of
> companies you actually partner with or are authorised to reference, per each
> brand's trademark-usage guidelines.
